# 肥鱼记忆字典 v3

- A1：交互原文，存储 pool=a；按 recordedAt 满 168 小时后进入自审查队列，发生时间独立保留。
- A2：自审查提取或普通写入的记忆、事项、实体、关系；默认归属，不自动进入核心。
- A2 活动池：最新版本记录满 30×24 小时后待清理；未明确审查先保留。批准后只退出活动索引和当前投影，原文、不可变版本与证据历史保留，不是物理擦除。归档覆盖声明不等于清理批准。
- A3：仅从当前 A2 条目再次提纯关键信息，kind=a3、pool=a3、depth=2；只在显式 memory_a3_write 调用后产生。不允许原文直接进入 A3、A3 作为后续层输入或进入 C。
- derived_only：A3 永远是归纳而非原始证据，不得标为 quote_verified。推断必须标 statementType=inference 并写明推理和不确定性；用户或助手原话均不自动成为事实。
- derivedFrom/sourceEntries：A2 父条目 ID 与精确版本、哈希及读取指针；只需两步即可追查 A2 与其原文。缺失或无效原文标 lineageBroken；当前父条目归档、退休或移池标 orphaned，A3 本身保留。
- coverage：必须声明此次审查的 scope 精确版本，covered 必须等于 derivedFrom，每条 notCovered 都须有理由；不声称已枚举全部语义相关信息，也不授权清理。
- a3：不可变版本与当前投影，日期保存在记录中。撤回后标 archived；醒来只显示计数与检索路标，绝不批量注入 A3 正文。
- B1（原 B）：独处统计，仅按日期、角色和小时聚合，不保存正文。
- B2：独处冲浪中明确选取的关键发现与判断，附 HTTP(S) 来源，标 external_reference；14×24 小时滑动删除，不保存整段独处过程，不等同经过事实验证。
- B3：肥鱼自己的喜好，kind=preference、subject=self、sourceNature=model_self_report；只记录明确自述，可修改、撤回或恢复，每次决定保留历史。B3 不会开启 B 池全文保存。
- self_report：喜好自述，不是经事实验证的结论。B3 可不附来源；可选原文只作为 context_only，上下文引文是否命中由 contextEvidenceStatus 单独表示。
- C：仅核心关系网的 entity 节点和 relation 有向边；肥鱼可用有理由、有版本的独立决策自主晋升或撤销。普通 memory、doing 和 preference 不得加入 C。
- 自审查：逐条有原文产物或明确省略理由，原子提交并保存不可变审查记录。自审本身不直接删除；满 168 小时且已完成自审的原文可由维护移出 A1，引用中的原始依据和管理员明确保留的原文仍保留，未审先保留。
- relation：from → to 表示该方向的关系；不补反向边、不推导传递关系，别名不自动合并实体。
- quote_verified：仅表示引文逐字定位到原文，不证明主张成立。supports 是支持关系的声明，也不是事实验证。
- sourceRoot：来源沿袭标识；不同标识不自动代表独立。重复读取或重复摘要不增加可信度。
- currentValidity=unknown：历史陈述、核心选择和喜好自述均不证明当前仍有效。
- archive：C 的不可变版本历史；撤销后历史 C 版本留存，当前条目回到 a2。
- b3：喜好的不可变版本历史；撤回后当前版本标 archived，历史喜好仍可查。

字典版本不可原地改变。v1、v2 和旧版本条目原样保留。
